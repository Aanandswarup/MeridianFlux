# Meridian Flux — Premium Watch Landing Page ⭐ Flagship

Flagship marketing site for a premium watch line: hero, showcase, pricing, testimonials, FAQ, and CTAs with scroll motion throughout.

## Run

```sh
npm install
npm run dev      # http://localhost:5173
npm run build    # single-file dist output
```

## Live

Deployed with GitHub Pages from `main` — see the repo's Deployments.

## Tech

React 19, Vite 7, Tailwind CSS 4, Framer Motion, `vite-plugin-singlefile`.
